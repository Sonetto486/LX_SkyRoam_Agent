====================================================
四、环境变量与配置文件
====================================================
1) 后端
- 参考模板：`env.example`
- 常用文件：`backend/.env`（按 `app/core/config.py` 的加载逻辑）

关键变量建议：
- DATABASE_URL
- REDIS_URL
- OPENAI_API_KEY / OPENAI_API_BASE / OPENAI_MODEL
- AMAP_API_KEY
- BAIDU_OCR_API_KEY / BAIDU_OCR_SECRET_KEY
- HOST / PORT / DEBUG

2) 前端
- 常用变量：REACT_APP_API_BASE_URL
- 当前 scripts 中默认：`http://127.0.0.1:8001/api/v1`

3) Docker
- `docker-compose.yml` 使用 `.env.docker`（如存在）
- 主要端口（当前配置）：
  - 前端：13000
  - 后端：8001
  - 高德 MCP：13002
  - 小红书 API：18002
  - PostgreSQL：5432


====================================================
五、安装与启动（开发常用）
====================================================
1) 后端安装
- 进入 `backend`
- `pip install -r requirements.txt`

2) 前端安装
- 进入 `frontend`
- `npm install`

3) 本地启动（Windows）
- 快速模式：`start-dev.bat`
- 全服务模式：`start-all-win.bat`

4) Docker 启动（推荐）
- 根目录执行：`start.bat`
- 或：`docker compose up -d --build`


====================================================
六、版本与兼容性建议
====================================================
1) Python 建议使用 3.10 或 3.11
2) Node.js 建议 18 LTS 或 20 LTS
3) PostgreSQL 建议 15（当前 compose 使用 pgvector/pg15）
4) 若使用 Playwright，请执行浏览器依赖安装（首次）：
   - `python -m playwright install`


====================================================
七、常见依赖问题
====================================================
1) 后端安装慢/失败
- 升级 pip：`python -m pip install --upgrade pip`
- 使用镜像源安装

2) 前端安装失败
- 删除 `node_modules` 和锁文件后重装
- 清理 npm 缓存后重装

3) 地图请求报错 INVALID_USER_KEY
- 检查 `AMAP_API_KEY` 是否有效与权限匹配

4) 启动后接口 404
- 检查后端端口、前端 API 基址、路由注册情况


====================================================
八、安全提示
====================================================
1) 请勿将真实 API Key、数据库密码提交到仓库
2) 建议 `.env`、`.env.docker` 加入忽略管理
3) 生产环境使用最小权限数据库账号
4) 日志避免输出完整密钥和 Token
